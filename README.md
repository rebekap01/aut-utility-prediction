# Automated Evaluation of the Utility of Creative Responses on the Alternate Uses Task

This repository contains the code and data for my Master's thesis project for MSc Behavioural Data Science at the University of Amsterdam. 

The data consists of human-generated and LLM-generated responses to the Alternate Uses Task (AUT) which evaluates creativity by asking participants to come up with creative uses of a common object (e.g. brick). Creativity consists of two components - how original or novel something is and how useful it is. While the automation of the evaluation of the former aspect has been heavily studied in the creativity literature, research on the automated evaluation of the latter is not nearly as widespread.

Therefore, this project aimed to identify the best predictor-model combination for predicting human utility ratings of responses to the AUT. Additionally, it wanted to investigate whether predictors derived from knowledge graphs (these link entities based on their relationships and thus help embed concepts in context) could help improve this prediction. A number of non-generative machine learning models (naive Bayes, logistic regression, k-nearest neighbors, random forest, XGBoost, LightGBM) were trained on various predictor combinations including: 
- number of words (elaboration),
- (inverse) frequency of response within the sample,
- semantic distance from AUT object (based on word embeddings),
- semantic distance from top 10 uses (either taken as most frequent from the sample or generated by knowledge graph),
- semantic distance from related uses (generated by knowledge graph). 

The best-performing model was an XGBoost model containing elaboration, frequency, inverse frequency, similarity to AUT object, USE embeddings, semantic distances to ten common uses, and eight related uses from a generative knowledge graph. However, knowledge graph predictors did not significantly contribute to the improvement of utility predictions.
